# Kavárna Zrnko – ukázka webu

Ukázka webu pro kavárnu od **[MadeByEmKo](https://madebyemko.cz)**. Název, adresa, ceny i kontakty jsou smyšlené.

**Živá ukázka:** https://madebyemko.github.io/zrnko/

## Co web obsahuje

- úvod s dortem dne a kávou, která je právě v mlýnku
- ukazatel „Otevřeno / Zavřeno“ podle aktuálního času
- menu online s přepínáním kategorií (káva, ne-káva, dorty a snídaně) a štítky jako novinka, vegan nebo bez lepku
- káva týdne s chuťovým profilem
- příběh kavárny a fotky
- fotky z Instagramu
- otevírací doba se zvýrazněným dneškem, mapa, navigace a tlačítko pro zavolání
- na mobilu spodní lišta s menu a navigací

Ve verzi pro skutečnou kavárnu si majitel menu, ceny i dort dne upravuje sám v jednoduché administraci a fotky z Instagramu se načítají automaticky.

## Technologie

Jeden soubor HTML, CSS a JavaScript bez knihoven. Rychlé načtení a přehledné zobrazení na mobilu.
